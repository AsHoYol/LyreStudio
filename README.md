# 原神弹琴播放器 · Genshin Lyre Studio

一个为原神风物之诗琴（以及晚风圆号等短按乐器）打造的本地弹奏辅助工具。
支持**自动演奏谱子**、**从弹奏视频自动提取乐谱**、**桌面浮窗控制**与**歌词式滚动显示**。

---

## 功能特性

### 🎹 两种演奏模式

- **音频模式**：内置合成器，直接通过扬声器试听，不占用游戏输入。
- **按键模式**：模拟真实键盘按键，由游戏内乐器直接发声。
- 无需游戏窗口焦点切换，按 F8 即开始。

### 🎬 视频转谱

- 导入本地弹奏视频，自动识别按键轨迹并生成可播放的 `.txt` 谱子。
- 支持 **21 键（3 排）/ 14 键（2 排）/ 4 键** 三种乐器布局。
- 内置 `calibrations/` 默认标定，选用对应布局即可自动适配。
- 支持用鼠标直接拖动/滚轮微调标定点，无需重新框选。
- 红绿圈实时预览，调参所见即所得。

### 🪟 桌面浮窗

- 无边框、置顶、可拖动的小窗。
- 显示当前曲目、播放进度、**下一首会播什么**。
- 浮窗内可直接播放/暂停、停止、切歌。

### 📜 歌词模式

- 右侧编辑器一键切换为滚动歌词视图。
- 播放时自动高亮当前行，并滚动到视野中央。

### 📂 播放列表

- 顺序 / 单曲循环 / 随机 三种循环模式。
- 支持加入当前、加入全部、查看编辑（上下移、删除、双击播放）。
- 未选中曲目直接播放时会自动从播放列表开始。

## 安装

### 环境要求

- Python 3.9+
- Windows / macOS / Linux（按键模式在 Windows 上效果最佳）

### 步骤

```bash
# 1. 克隆仓库
git clone https://github.com/你的用户名/genshin-lyre-studio.git
cd genshin-lyre-studio

# 2. 创建虚拟环境（推荐）
python -m venv .venv
# Windows
.venv\Scripts\activate
# macOS/Linux
source .venv/bin/activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 启动
python app.py
```
